# Page Pulse Frontend

This is the React frontend for **Page Pulse**, a web application that audits any website by accepting a URL and displaying a report with useful webpage information.

## Features

- Enter a website URL
- View HTTP status
- View response time
- Display page title
- Display meta description
- Show H1 tag count
- Show images without alt text
- Show approximate word count
- Display error messages for invalid input

## Tech Stack

- React
- Vite
- Axios
- CSS

## Run Locally

```bash
npm install
npm run dev
```

The application runs at:

```
http://localhost:5173
```
